# 提問漢堡：核心問題／情境／期待幫助／已做努力

上一篇拆了精準提問的各種元素，但實戰中你需要一個好記、能快速組裝的框架，不然臨場還是會漏。這篇給你一個：把一個好問題想像成一個漢堡，四層疊起來就完整。

## 漢堡的四層

由內而外：

- **肉（核心問題）**：最中心、最重要的一層——你到底卡在哪、要問什麼。一句話講清楚。這是整個漢堡的主角，模糊不得。
- **生菜番茄（情境）**：包住核心的背景脈絡。用人、事、時、地、物或 5W2H 把「這件事怎麼發生的」講清楚，讓對方快速進入狀況。
- **醬料（期待幫助）**：你希望對方提供什麼。是要他給方向、幫你看一段邏輯、確認你的判斷、還是做決定？講明白，對方才不用猜你要什麼。
- **漢堡皮（已做努力）**：包在最外層——你已經查了什麼、試了什麼、結果如何。它讓對方知道你不是伸手牌，也避免他重複建議你已經試過的方法。

四層的口訣：**核心問題、情境、期待、已做努力。** 缺了核心問題，對方根本不知道你要幹嘛；缺了情境，問題難以下嚥；補上已做努力，回來的答案才精準。

## 一個範例

把四層裝進一個真實的 QA 提問：

> **（已做努力）** 我查過 API 文件也搜過內部討論，沒找到這個欄位的定義；自己用 Postman 試了三種輸入，行為不一致。
>
> **（情境）** 測訂單匯出功能時，`status` 欄位在某些訂單回 `null`、某些回空字串，但文件只寫會回字串。
>
> **（核心問題）** 想確認：`null` 和空字串是預期內的合法值嗎？還是其中一個是 bug？
>
> **（期待幫助）** 如果你知道這欄位的規格，幫我確認一下；不確定的話，能不能指我去問哪位比較快。

對方讀完，完全不用反問就能回答，而且知道你已經做足功課、只是卡在一個他能拍板的點上。

## 臨場不完美怎麼辦

有時候你還沒想清楚，但又需要當場討論——這很正常，不用等到組好完美的漢堡才開口。一個降低壓力的開場很好用：

> 「我這個想法可能還沒那麼成熟，先說出來跟你討論一下。」

這句話做兩件事：一是降低對方「要給標準答案」的壓力，把對話變成一起想，而不是考你；二是讓你能邊講邊釐清，常常講著講著自己就想通了。會提問的人不是每次都完美，是知道怎麼在不完美時也讓對話有效。

## 帶得走

- 提問漢堡四層：核心問題（肉）、情境（生菜番茄）、期待幫助（醬料）、已做努力（漢堡皮）。
- 缺核心問題對方不知你要什麼；缺情境問題難下嚥；補上已做努力答案才精準。
- 一個組好的問題，能讓對方不用反問就回答——這是提問效率的極致。
- 還沒想清楚也能問：用「想法還沒成熟，先討論」降低壓力，邊講邊釐清。
